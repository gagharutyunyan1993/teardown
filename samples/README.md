# samples/

Rules enforced by the harness: nothing here is executed, traced, chmod-ed, edited or dumped raw into the agent context.
Use `/triage <path>` for a bounded first look and `/analyze <path>` for a report in `analysis/`.
Test fixtures do not live here; they are synthetic and go under `tests/fixtures/`.
